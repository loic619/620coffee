# Acaphe

Vietnamese physical coffee quotes published by Acaphe.

- **Upstream:** https://acaphe.com/
- **Cadence:** daily
- **Scope:** quoted physical prices as published.
- **Processing:** parsed into JSON with normalised field names and ISO 8601
  dates. Quotes are as printed.

Datasets in this directory are indexed in `/catalog.json` under source `acaphe`.
